# Blasphemous 2 Save Parser

Parses your save file and determines what you're missing. Includes some links to help you find your way.

- In-game screenshots are my own.
- Sprites were extracted from the game using [AssetRipper](https://github.com/AssetRipper/AssetRipper).
- Special thanks to the Blasphemous Speedruns community for the [incredible spreadsheet](https://docs.google.com/spreadsheets/d/1vC5B-OesvM7ITWKGZ34kaK_sdrBZGtMeyof91JFNQkc) which saved me countless hours!
